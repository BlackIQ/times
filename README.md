# [Amirhossein Jornal](http://jornal.amirhossein.info)

Source code of my personal jornal.

## Structure

This is the stucture of project.

- Frontend
  - Language: TypeScript
  - Framework: Next.js
  - UI Library: TailwindCSS
- Backend
  - Language: Python
  - Framework: FastAPI
  - ORM: SQLAlchemy
- Database
  - Engine: PostgreSQL
- Web Server
  - Server: Nginx
