# Sky - Backend

**Sky** is a social media colaborated with [Maedeh Khorasani](https://github.com/MaedehSKh80).

We worked on some projects before this project and now it's time to work on something much bigger.

## Sky features

Well as a basic and mini social media, it doesn't have very much features. But as it is, you can:

- Signup
- Signin
- Publish a post
- Comment on another one post
- Make a short note
- Reply on other notes
- Follow people
- Like and share media
- Send direct message
