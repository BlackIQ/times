# [Amirhossein Blog](http://blog.amirhossein.info)

Source code of my personal blog.

## Structure

This is the stucture of project.

- Frontend
  - Language: TypeScript
  - Framework: Next.js
  - UI Library: Material UI
- Backend
  - Language: Python
  - Framework: FastAPI
  - ORM: SQLAlchemy
- Database
  - Engine: PostgreSQL
- Web Server
  - Server: Nginx
